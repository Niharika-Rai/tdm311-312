# Data Mine Corporate Partners Project

TDM 311-312 stands for the "Data Mine Corporate Partners." 

I worked as an Undergraduate Data Science Researcher via the Data Mine Corporate Partners Program, and my mentor was from Carnival Cruise Line. In this project, I created an interactive Power BI Dashboard that would help the company monitor diesel engine performance for 3 ships over 3 years, identify anomalies in engine component behavior, and improve engine reliability and operational efficiency through data-driven insights. 

Data Mine Symposium Poster and Video Link: https://datamine.purdue.edu/carnival-cruise-line/
